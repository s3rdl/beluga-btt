# KiCad 3D models

- `Soldered_333095_v1.1.1.step` is the manufacturer STEP model for the Soldered 333095 ADS1115 breakout, hardware revision V1.1.1.
- `Olimex_ESP32-POE-ISO-EA-envelope.wrl` is a board-envelope model based on the official Olimex ESP32-POE-ISO Rev.N perimeter. It includes the side notch and PCB thickness, but does not model components. The footprint places it 2 mm above the carrier PCB, matching the Soldered module's 3D-model offset.

The Soldered STEP model and source board CAD are from the manufacturer's repository:

<https://github.com/SolderedElectronics/ADC-16-bit-ADS1115-4-channel-with-PGA-breakout-hardware-design>
